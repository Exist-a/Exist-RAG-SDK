## 4. 目录结构

```
rag-sdk/
├── packages/                    # SDK 核心包（7个）
│   ├── core/                   # 核心类型、接口、规范
│   ├── runtime/                # 运行时组件
│   ├── indexing/               # 文档索引管道
│   ├── adapters/               # 外部服务适配器
│   ├── observability/          # 可观测性
│   ├── eval/                   # 评估框架
│   └── utils/                  # 工具函数

│   ├── architecture/           # 架构文档
│   ├── sdk/                    # SDK 文档
│   ├── pipeline/               # 管道文档
│   ├── indexing/               # 索引文档
│   ├── eval/                   # 评估文档
│   ├── observability/          # 可观测性文档
│   ├── decisions/              # 决策记录
│   ├── examples/               # 示例

├── .vscode/                    # VSCode 配置
```

```bash

```

## 7. 约束规则

1. **文档语言**：所有文档必须使用中文生成
2. **包结构**：每个包必须包含独立的 package.json
3. **模块系统**：使用 ES Modules (`"type": "module"`)
4. **禁止事项**：当前阶段禁止编写业务逻辑和添加第三方依赖
5. **docs 目录不上传 Git**：`docs/` 目录仅用于 AI 协作和本地开发者阅读，已加入 `.gitignore`
